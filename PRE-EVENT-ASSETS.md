# Pre-event assets disclosure

This disclosure is based on the repository history and identifies material that existed before the event implementation work began.

## Existing project material

- The Agentic Slice Kit scaffold, including the `slice/`, `demo/`, `web/`, `scripts/`, `tests/`, `.devcontainer/`, and supporting documentation structure.
- Early EDUNEXUS specification and design documents committed before the Day 1 implementation commits.
- General-purpose starter patterns for persistent run state, model calls, budgets, retrieval, callbacks, and smoke testing supplied by the starter kit.

## Third-party software and services

- Python open-source packages declared in `requirements.txt` and their transitive dependencies.
- React, ReactDOM, Babel, Vite, and other frontend packages declared or loaded by the frontend.
- External model-provider APIs and pretrained embedding models. These models and services were not created by the team.
- FAISS/vector-search, PDF parsing, SQLite, FastAPI, Streamlit, and related open-source infrastructure used by the application.

## Created during the event

The EDUNEXUS learning experience and its Day 1/Day 2 implementation work—including the adaptive diagnostic, diagnosis, remediation, verification, revision, testing, learner-memory, document-grounding, media, and integrated UI behavior—appears in the event-period commits on the default branch.
